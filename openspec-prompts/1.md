# DML Device Implementation Task

## CRITICAL RULES
- Implement device behavior and registers only — preserve existing code and imports.
- ONLY edit these files:
  - DML device implementation: `simics-project/modules/<device_name>/<device_name>.dml`
  - Python unit tests: `simics-project/modules/<device_name>/test/*.py`
- **MANDATORY**: Read and follow `.specify/memory/DML_Device_Development_Best_Practices.md` for timer/event implementation
- DO NOT remove or change any import statements (especially:
`import "<device_name>-glue.dml";`
`import "<device_name>-dia.dml";`).
- Implement comprehensive Python unit tests to verify device behavior per spec.

## FORBIDDEN ACTIONS
❌ Removing any import statements
❌ Modifying config/XML/Makefiles/other files
❌ Modifying files outside: `simics-project/modules/<device_name>/<device_name>.dml` and `simics-project/modules/<device_name>/test/`
❌ Editing auto-generated files: `<device_name>-glue.dml`, `<device_name>-dia.dml` (these are auto-generated!)
❌ Implementing cycle-accurate timer models or using external clock inputs for timers
❌ Using session/saved variables or manual cycle counting for timer implementation
❌ Implementing timers WITHOUT using DML `event` objects and Simics time APIs

## MANDATORY STEPS
1. **Read the device spec**: `specs/001-read-the-simics/spec.md`
2. **Identify device**: `ls simics-project/modules/<device_name>`
3. **If device requires timer/event functionality**:
   - **MUST READ**: `.specify/memory/DML_Device_Development_Best_Practices.md` (Section: Timer Device)
   - Implement using `event` objects with `post()`, `remove()`, `posted()` methods
   - Use `SIM_time()` for time tracking, NOT cycle counting or session variables
4. **Implement DML device behavior** in: `simics-project/modules/<device_name>/<device_name>.dml`
   - Read/write handlers and side effects
   - Interrupts and state transitions
   - For timers: Use event-based implementation (see step 3)
   - Preserve all import lines and auto-generated register usage
5. **Implement Python unit tests** in: `simics-project/modules/<device_name>/test/`
   - Create clock object: `clk = SIM_create_object('clock', 'clk', freq_mhz=1)`
   - Assign to device: `device.queue = clk`
   - Test all register operations, interrupts, and timer behavior
   - Ensure test coverage matches spec requirements
6. **Commit changes**: `git add simics-project/modules/<device_name>/<device_name>.dml simics-project/modules/<device_name>/test/*.py && git commit`

## EXIT: when
- All register behaviors match `specs/001-read-the-simics/spec.md` exactly
- All required imports remain intact and unmodified
- Timers implemented using DML events (if applicable)
- Python unit tests verify all spec requirements and configure clock queue
