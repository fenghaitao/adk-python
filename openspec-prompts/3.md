8. **For Python test fixes** in `simics-project/modules/<device_name>/test/*.py`:

9. **For DML fixes**: `simics-project/modules/<device_name>/<device_name>.dml` - fix logic bugs, NOT rewrite - DO NOT touch glue/dia files!
10. Re-run tests to validate
11. Commit changes and loop back to #5 until ALL tests pass!
