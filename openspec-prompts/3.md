## TROUBLESHOOTING GUIDE

**Simulation crashes with segfault:**
→ DML has `connect` blocks but test missing mock connections → Apply Pattern 6

**Tests keep failing after DML edits:**
→ **FORGOT TO REBUILD**: Run `cd simics-project && gmake <device_name> 2>&1 | tee bld.log` after EVERY DML change

**DML compilation errors mentioning "except":**
→ **WRONG LANGUAGE SYNTAX**: DML uses `catch { }` NOT Python's `except:`
→ Replace all `} except {` with `} catch {` or do NOT use exception handling

**AttributeError: '<device>' object has no attribute '<attr_name>' in module_load.py:**
→ **Wrong attribute name in get_status() function**
→ Auto-generated attributes follow pattern: `obj.<BankName>_<RegisterName>`
→ Find bank/register names: `grep "^bank " modules/<device>/<device>.dml` and `grep "register " modules/<device>/<device>.dml`
→ Example: DML with `bank MyRegs { register CTRL { ... } }` creates attribute `obj.MyRegs_CTRL`
  * Wrong: `obj.regs_ctrl` (mismatched names)
  * Correct: `obj.MyRegs_CTRL` (exact bank + register names)
→ If no suitable attribute exists, remove status code or return empty: `return []`

**Events/interrupts don't fire when expected:**
→ Missing signal interface connections → Apply Pattern 6
→ Check DML timing calculations and `SIM_continue()` cycles
→ **Multi-clock-domain issue**: If test has multiple clocks with different frequencies AND quantum >> fastest clock period:
  * Adjust quantum: `cli.run_command('cpu-switch-time seconds = 1e-6')` (for 1 MHz)
  * Formula: `quantum = 1 / fastest_clock_freq_hz`
  * Not needed if test has only ONE clock
