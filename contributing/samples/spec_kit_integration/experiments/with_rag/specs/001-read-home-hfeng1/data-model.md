# Data Model: Simics Watchdog Timer

## Overview
This document describes the data model for the Simics Watchdog Timer device. The watchdog timer is a 32-bit decrementing timer that generates interrupt and reset signals based on configurable parameters.

## Entities

### Watchdog Timer
The main device entity that encapsulates all watchdog timer functionality.

**Fields:**
- `counter`: 32-bit current counter value
- `load_value`: 32-bit initial counter value
- `interrupt_enabled`: Boolean flag for interrupt generation
- `reset_enabled`: Boolean flag for reset generation
- `interrupt_status`: Boolean flag indicating interrupt pending
- `locked`: Boolean flag indicating register protection status
- `integration_test_mode`: Boolean flag for integration testing

**Relationships:**
- Contains Configuration Registers
- Connects to Clock/Reset Interface
- Generates Interrupt/Reset Signals

**State Transitions:**
1. **Idle**: Timer not running
2. **Counting**: Timer decrementing
3. **Interrupt_Pending**: First timeout occurred, interrupt asserted
4. **Reset_Pending**: Second timeout occurred, reset asserted

### Configuration Registers
Memory-mapped registers that control and monitor the watchdog timer.

**Fields:**
- `WDOGLOAD`: Load value register (32-bit)
- `WDOGVALUE`: Current counter value register (32-bit, read-only)
- `WDOGCONTROL`: Control register with interrupt and reset enable bits
  - `int_en`: Interrupt enable bit
  - `res_en`: Reset enable bit
- `WDOGINTCLR`: Interrupt clear register (write-only)
- `WDOGRIS`: Raw interrupt status register (read-only)
- `WDOGMIS`: Masked interrupt status register (read-only)
- `WDOGLOCK`: Register lock/unlock control
- `WDOGITCR`: Integration test control register
- `WDOGITOP`: Integration test output set register
- `WDOGPERIPHID0-7`: Peripheral identification registers
- `WDOGPCELLID0-3`: PrimeCell identification registers

**Validation Rules:**
- WDOGLOAD: Valid range 0x00000000 to 0xFFFFFFFF
- WDOGCONTROL: Only bits 0 and 1 are used, others reserved
- WDOGLOCK: Write 0x1ACCE551 to unlock, any other value to lock
- WDOGITCR: Only bit 0 is used, others reserved

### Interrupt/Reset Signals
Output signals generated by the watchdog timer.

**Fields:**
- `wdogint`: Interrupt output signal
- `wdogres`: Reset output signal

**Behavior:**
- `wdogint`: Asserted when counter reaches zero and interrupt is enabled
- `wdogres`: Asserted when counter reaches zero for second time without interrupt clearing

### Clock/Reset Interface
Input signals that control the watchdog timer operation.

**Fields:**
- `wclk`: Working clock input
- `wclk_en`: Clock enable input
- `wrst_n`: Working clock domain reset (active low)

## Device State Management

### Counter Operation
The watchdog timer operates as a 32-bit down counter:
1. Counter is loaded with value from WDOGLOAD register
2. Counter decrements on each clock cycle when enabled
3. When counter reaches zero:
   - If interrupt enabled and no interrupt pending: Generate interrupt
   - If interrupt pending and reset enabled: Generate reset
4. Counter restarts from WDOGLOAD value after reaching zero

### Lock Protection
The WDOGLOCK register provides protection against unauthorized register changes:
1. When locked (default state):
   - All registers except WDOGLOCK are write-protected
2. To unlock:
   - Write 0x1ACCE551 to WDOGLOCK
3. To lock:
   - Write any value other than 0x1ACCE551 to WDOGLOCK

### Integration Testing
The integration test registers allow direct control of output signals:
1. WDOGITCR enables integration test mode
2. WDOGITOP allows setting output signals directly
3. Normal timer operation is disabled during integration test mode

## Timing Requirements
- Clock frequency: Determined by wclk input
- Reset assertion: Immediate on second timeout
- Interrupt assertion: Immediate on first timeout
- Register access: Single clock cycle for reads/writes (when unlocked)

## Error Handling
- Invalid register writes (when locked): Ignored
- Invalid load values: Accepted but may result in immediate timeout
- Clock disabled: Counter stops decrementing
- Reset received: All registers return to default values except ID registers
